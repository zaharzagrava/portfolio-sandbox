# Gaps: J02 — Seller to first sale

Every missing or broken hand-off between the domains of this journey, found by reading the code and the capability specs (static reading only; nothing was run) against [`spec.md`](spec.md). This is the implementation agent's to-do list; each row names the domain (capability) that must fix it. Paths are under `packages/backend/` unless marked `ROOT/`; line numbers are of the code at the time of writing. Rows marked **blocker** stop the journey from running at all.

J01's gaps apply here unchanged and are not repeated: the relay envelope (J01 G-01: the poller wraps the envelope as `{payload, extra, error}` and `parseEnvelope` turns every event into `<aggregate>.legacy`), the missing control surface for jobs, consumers and clock, the local monolith's composition, and the `order.paid` payload and payment initiation (J01 G-02, G-03, G-11). J02 adds the rows below.

Existing journey tests: none. `test/journeys/` holds only `README.md`; `jest-journeys.json` (regex `*.journey-spec.ts`, `maxWorkers: 1`, 180 s) and `pnpm test:journeys` exist. Helpers available: `test/utils/async-helpers.ts` (`waitFor`), `test/utils/sse-client.ts`. Per-domain e2e specs call projectors directly and mock config, so they never see the relay's real message shape.
