# Open Decisions for J04 (answered unattended)

Format: `[TAG] question → default taken → why`. BREAKING first, then CONTRACT, then LOCAL. The human reviews BREAKING and CONTRACT lines first. Decision policy: most production-grade option the Interview-Prep notes and the constitution support; no external clients to keep compatible, so correctness, security, observability and clean domain boundaries win over preserving today's behaviour.

## BREAKING (changes behaviour or an API/UI contract that exists today)

- [BREAKING] `products.events` is an untyped `{productId}` notification that consumers answer by re-reading the product table (`product.service.ts:100-107`, `product-search.projector.ts`) → the journey consumes only S05's versioned `catalog.product_*` snapshot events; search, pickup copy, device feed and Shopify push read their data from the event copy and a `productVersion` guard, never from the table → constitution IX.7 R3 and IX.8, IV.4; the table-reading projectors break under D-12 and cannot be replayed.
- [BREAKING] Every stock writer must go through `applyStockDelta` and therefore emit `catalog.product_updated`; today checkout, order jobs, auctions and payments decrement `Product.quantity` with raw SQL and emit nothing (`checkout.service.ts:148-153`, `auction.jobs.ts:70`, `payment.service.ts:190`) → they change to the stock command with an `operationId` → otherwise search `inStock` and the Shopify inventory go stale after an online sale, which defeats the journey's single-source-of-truth rule.
- [BREAKING] Projector/consumer group names become contract: `search-indexer` → `search-product-index`, `integrations-stock-push` kept, `pickup-availability` kept, new `offline-sync-feed` → the control surface (pause, resume, replay, lag) is addressed by group name and the journey must name them; consumers start `fromBeginning`, so a rename replays and is safe because every consumer is version-guarded.
- [BREAKING] Outbox relay value: the poller wraps the envelope as `{payload, extra, error}` and `parseEnvelope` turns every event into `<aggregate>.legacy`, so the pickup projector and the webhook router drop everything (`outbox-publisher.service.ts:90-94`, `envelope-parser.ts:24-48`) → the relay publishes the bare envelope in every mode (same as CDC); the e2e specs stop feeding `Outbox.payload` straight to `project()` → J01 already requires this; without it no hop in this journey works on the default relay.
- [BREAKING] Import progress channel `job:{jobId}` (creator-only, replay off) → `import:{importId}` (member policy, terminal events replayable); journey and web follow the new name → S07 decision; the journey needs a terminal event a late subscriber still receives.
- [BREAKING] Near-me responses are bare arrays with a numeric `price` (`pickup.controller.ts:55-69`) → `{items, nextCursor}` with `priceMinor` and `currency`, strict parameter validation → S19 decision; the journey asserts the new envelope, so W02/S48 callers change.
- [BREAKING] Product search and the product write routes move (`GET /products/search` returns `{total, hits, suggestions}`; `POST /products/shops/:shopId`) → `GET /products/search` returns S32's `{searchId, mode, items[], total {value, exact}, nextCursor, degraded}`; writes live under `/shops/:shopId/products` → S05/S32 decisions; the journey asserts the new shapes only.
- [BREAKING] Shopify adapter has a hard-coded provider URL and the stock push is a combined-hash comparison that can overwrite a local sale (`shopify.provider.ts:5,97`, `integration-sync.service.ts:121-173`) → provider host from configuration with a local-profile allow-list, and the three-way merge on `syncedStock` with conditional writes → S08 decision; a double is impossible otherwise and AS-14 would lose a sale.
- [BREAKING] Offline pull feed is filled by a database trigger on `Product`, so it captures every writer without the catalog knowing (`migrations/20261001360000-offline-sync.js:48-67`) → filled by the `offline-sync-feed` consumer of `catalog.product_*` events → S09 decision; trigger and FK across owners are banned (IX.4), and AS-13 needs the feed to be an event-driven read model.
- [BREAKING] Reconciliation zeroes stock for provider-deleted products with raw SQL and no event (`integration-sync.service.ts:186`) → zeroing goes through `applyStockDelta` so search and the feed see it → keeps every copy convergent.
