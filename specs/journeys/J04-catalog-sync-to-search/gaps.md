# Gaps: J04 — Catalog sync to search

Every missing or broken hand-off between the domains of this journey, found by static reading of the code and the capability specs against [`spec.md`](spec.md). Nothing was run. This is the implementation agent's to-do list; each row names the capability that must fix it. Paths are under `packages/backend/` unless marked `ROOT/`. Rows marked **blocker** stop the journey from running at all.

J01's gaps apply here unchanged and are not repeated: the relay envelope (J01 G-01), the missing control surface for jobs, consumers and clock, and the local monolith's composition. J04 adds the rows below. Existing journey tests: none (`test/journeys/` holds only `README.md`; `jest-journeys.json` and `pnpm test:journeys` exist; helpers `test/utils/async-helpers.ts` `waitFor` and `sse-client.ts`).
