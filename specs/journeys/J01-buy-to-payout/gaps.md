# Gaps: J01 — Buy to payout

Every missing or broken hand-off between the domains of this journey, found by reading the code (static reading only; nothing was run) against [`spec.md`](spec.md). This is the implementation agent's to-do list; each row names the domain (capability) that must fix it. Paths are under `packages/backend/` unless marked `ROOT/`; line numbers are of the code at the time of writing. Rows marked **blocker** stop the journey from running at all.

Existing journey tests: none. `test/journeys/` holds only `README.md`; `jest-journeys.json` and `pnpm test:journeys` exist. Helpers available: `test/utils/async-helpers.ts` (`waitFor`), `test/utils/sse-client.ts` (`readSse`). Per-domain e2e specs call projectors directly (`listener.project([event])`, e.g. `libs/domains/payments/finance.e2e-spec.ts:90-92`) and so never see the relay's real message shape.
