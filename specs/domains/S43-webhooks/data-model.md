# Data model: S43 — Webhook delivery to shops

Owner of every item: `domain:developer-platform` (registry `packages/backend/db/ownership.ts`). No foreign keys to another owner's table.

## Postgres

### `WebhookEndpoint` (exists; changed)

| Column | Type | Notes |
|---|---|---|
| `id` | uuid PK | generated by the service before insert (secret sealing context) |
| `shopId` | uuid NOT NULL | plain ID; **FK to `Shop` dropped** (contract migration) |
| `url` | text | as entered (≤ 2,048) |
| `urlNormalized` | text NOT NULL | lower-case host, no default port, no fragment |
| `events` | text[] | 1–20 distinct catalogue types |
| `apiVersion` | text | supported by S42 |
| `status` | text | `enabled` \| `disabled` (replaces `enabled` boolean) |
| `disabledReason` | text null | `manual` \| `auto_failing`; null when enabled |
| `failingSince` | timestamptz null | start of the failure window |
| `secretSealed` | text | `SecretBox` bound to `webhook-endpoint:<id>` |
| `previousSecretSealed` | text null | |
| `previousSecretExpiresAt` | timestamptz null | |
| `createdAt`, `updatedAt` | timestamptz | |

Indexes: unique `("shopId","urlNormalized")`; `("shopId","createdAt" desc,"id" desc)` for the list; partial `("failingSince") WHERE status='enabled' AND "failingSince" IS NOT NULL` for the sweep; `("shopId") WHERE status='enabled'` for routing.

State machine (`domain/endpoint-status.ts`): `enabled --disable(manual|auto_failing)--> disabled`; `disabled --enable--> enabled` (clears `failingSince`, breaker, failure count). Any other pair → `409 endpoint_state_conflict`. Auto-disable only when `failingSince <= now - 3 d` (inclusive).

### `WebhookEndpointHistory` (new, append-only, kept 400 days)

`id` uuid PK, `endpointId` uuid, `shopId` uuid, `facet` (`created|url|events|api_version|status|secret_rotated|previous_secret_expired|deleted`), `fromValue` text null, `toValue` text null (never a secret; URL facets store the host only), `actorId` uuid null, `createdAt`. Index `("endpointId","createdAt")`, `("createdAt")` for the purge job. Not FK-linked to the endpoint (survives deletion).

### `WebhookShopCounter` (new)

`shopId` uuid PK, `endpoints` int CHECK (`endpoints` BETWEEN 0 AND 20). Incremented/decremented in the endpoint's transaction; the CHECK is the store-level invariant.

### Routing receipts

Not a table of this domain: the S53 inbox (`infrastructure:inbox`, key = source `eventId`, group per consumer). A receipt is committed only after every endpoint message of the event is accepted by the queue.

### Outbox rows

`developerplatform.webhook_endpoint_disabled` v1 and `developerplatform.webhook_endpoint_changed` v1 (spec names use `developer_platform.`; see gaps.md) via the S53 outbox, aggregate type `developer_platform`, aggregate id = endpoint id.

## DynamoDB `WebhookAttempts` (delivery log + state, TTL 30 days)

| Item | Key | Attributes |
|---|---|---|
| Delivery | `PK=endpoint#<id>`, `SK=delivery#<eventId>` | `deliveryId`, `type`, `kind` (`event|replay|ping`), `state`, `attempt` (next number), `nextAttemptAt`, `claimedAt`, `body` (≤ 256 KiB), `shopId`, `createdAt`, `expiresAt` |
| Attempt | `PK=endpoint#<id>`, `SK=attempt#<startedAt>#<attemptId>` | `deliveryId`, `eventId`, `type`, `attempt`, `durationMs`, `status?`, `ok`, `error?`, `responseSnippet?` (≤ 1 KiB), `replay`, `expiresAt` |

Delivery states: `queued → delivering → delivered | retry_scheduled → delivering … | exhausted | cancelled (endpoint_disabled|endpoint_deleted|shop_deleted) | failed (payload_too_large)`. Replay/ping deliveries go `queued → delivering → delivered | failed` and never to `retry_scheduled`. Reads filter `expiresAt > now` at read time (AS-60, AS-67). Never stored: signature, request headers, secrets, URL path/query.

## Redis (disposable)

- Breaker per endpoint: `{failures, openUntil, probeLease}`; never source of truth; a store error means "closed" plus `webhook_breaker_degraded_total`.
- S52 cache of per-shop subscriptions (`id, url, events, apiVersion, status, sealed secrets, expiry`), cross-instance invalidation, ≤ 5 s staleness; status is read from the store at each attempt.

## SQS

`webhook-deliveries.fifo` (group = endpointId, dedup = event id + attempt kind) + DLQ with redrive; message = `{endpointId, eventId, deliveryId, kind, attempt}` (no body, no secret). Retries beyond the lane: S49 job `webhooks.retry` with idempotency key.

## Event catalogue (constant)

11 types, `{type, description, resource, since}`: `order.paid`, `order.cancelled`, `order.refunded` (resource `order`), `product.created|updated|archived|deleted|stock_low` (`product`), `payout.paid|failed` (`payout`), `webhook.ping` (`ping`).

## Validation rules (summary)

URL ≤ 2,048, https, port 443, no user-info/IP literal/`localhost`, public addresses only; events 1–20 distinct from the catalogue; `apiVersion` supported; `overlapHours` integer 1–72; `limit` 1–100; unknown properties rejected; body ≤ 256 KiB rendered.
