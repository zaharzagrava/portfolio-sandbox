## Implementation notes (not spec changes)

- T048 (US3): the wake job's payload is the delivery id only (`contracts/services.md`), so the held message (line, `DeliveryMessage`, `staleAt`, `wakeAt`) waits in Redis under `notif:held:<deliveryId>` (new port `HELD_DELIVERY_STORE`, kept the wait + 2 days).
