## D. Work list (suggested order)

1. **Contracts first.** Add the schemas of Provides to `packages/contracts` (A40): install request/response, Woo connect, integration and page, sync request, quarantine item and page, conflict and page, report and page, event schemas; problem `code`s of FR-073. Add `integrations.manage` use (A15) and the new rate-limit policies to S50's registry.
2. **Migration (expand/contract, `lock_timeout`).** Drop the `Shop` foreign key; narrow the provider check to `shopify|woocommerce`; widen `status` to `ACTIVE|PAUSED|NEEDS_REAUTH|DISCONNECTED` and map `ERROR → NEEDS_REAUTH`; add `Integration` columns (`pausedReason`, `lastError`, `locationId`, `connectedBy`, `consecutiveFailures`, `breakerOpenUntil`, `nextSyncAt`, `updatedAt`), `SyncCursor` lease columns (`holder`, `expiresAt`, `fence`), `ExternalLink` columns (`contentDigest`, `syncedStock`, `remoteUpdatedAt`, `lastStockWriteAt`, `lastLocalVersion`, `state`), `SyncQuarantine` columns (`payloadDigest`, `reasonCode`, `status`, `occurrences`, `firstSeenAt`, `lastSeenAt`, `resolution`, `dismissedBy`), the new tables of Section C with registry entries, the partial unique `(provider, externalShop) WHERE status <> 'DISCONNECTED'`, a per-shop count rule enforced by the store (III.6), and the trigger that refuses updates of finished `ReconciliationRun` rows. Data steps (separate, not at startup): rename `ExternalLink.externalId` from `<productId>` to `<productId>:<firstVariantId>` and let the first backfill create the other variants; re-seal credentials with the integration context (A17, A45).
3. **Domain layer.** Pure modules: provider normalisation per provider, decimal money parser, stock merge, integration status machine with `assertNever`, watermark arithmetic, retry classification and backoff, breaker, reconciliation classification and mass-deletion rule, webhook verification rules, store-address classification (A5, A6, A10, A11, A18, A33, A36). Ports for repositories, provider gateway, clock, queue, catalog commands.
4. **Provider adapters.** Shopify (OAuth exchange, `shop.json` currency and primary location, variants, inventory levels with `changeFromQuantity`, webhook registration, `Link` host check, envelope validation, configured API version) and WooCommerce (REST v3, keys check, `modified_after`, variations, webhook registration with generated secret, signature) behind the one port; the fake becomes `test/fakes/fake-shopify.ts` and `fake-woocommerce.ts` HTTP servers; delete `infra/fake.provider.ts` and the `fake` branches (A13, A16, A18, A19, A22).
5. **Connection API.** Install, callback, Woo connect, list, detail, pause, resume, disconnect, sync-now, reconcile-now; transitions as conditional updates plus history plus outbox; `integrations.manage`; cross-tenant 404s; limits (A14, A15, A35).
6. **Sync engine.** Lease with fencing, run records, page checkpoints, budgets and continuations, due-time scheduling with jitter, shop-status check through tenancy's R1, link upserts, catalog calls through R1 outside transactions, stale/concurrent guards, queue message validation (A23–A29, A31).
7. **Stock.** Merge on `syncedStock`, inbound deltas with deterministic operation IDs, outbound conditional writes, the `products.events` consumer (version guard, filters, coalescing, DLQ), stale-read guard, conflict queue and routes (A4–A9).
8. **Quarantine** with dedupe, codes, auto-resolve, routes, mass-drift halt (A30).
9. **Webhooks.** Raw body only, per-provider parsing, signature, timestamp, receipts, fast ACK, `503` on enqueue failure, limits, paused/disconnected handling (A20–A22).
10. **Resilience.** Shared bucket plus `penalize`, `Retry-After`, retry policy, timeouts, breaker, token refresh single-flight, `NEEDS_REAUTH` (A32, A33).
11. **Reconciliation.** One message per integration on the backfill queue, chunked comparison, direct-read confirmation, guard, immutable reports and routes, lag alert (A36, A37).
12. **Lifecycle and operations.** Tenancy consumers, retention job, events, metrics and logging rules, startup configuration validation, barrel and module exports, apps wiring (`apps/projector` imports `IntegrationsProjectorModule`) (A34, A38, A39, A42).
