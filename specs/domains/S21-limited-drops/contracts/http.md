# HTTP contract: S21 — Limited-Drop Auctions

Prefix `/api`. Errors are `application/problem+json` with `type, title, status, detail, instance, requestId, code` plus the extension members named below. Schemas live in `packages/contracts/src/auctions/` (`auction.ts`) and are the only source of the DTOs (controllers use `createZodDto`-style pipes from them; the ORM row is never returned). Money fields are integers in minor units.

| Route | Guards / headers | Request | Success | Errors (`code`) |
|---|---|---|---|---|
| `POST /shops/:shopId/auctions` | `RequiresShopEntitlement('auctions')` above `ShopScoped('products.write')`; `Idempotency-Key` | `auctionCreateRequestSchema` `{productId, title, startingPriceMinor, minIncrementMinor, reservePriceMinor?, startsAt, endsAt}` (strict) | `201 auctionMemberSchema`, `Location: /api/shops/:shopId/auctions/:id`, `Idempotency-Replayed` on replay | `400 validation_failed`; `404 product_not_found`, `404 shop_not_found`; `403 entitlement_required {feature}`, `403 shop_suspended`; `409 auction_exists_for_product`, `409 idempotency_in_flight`; `422 reserve_below_starting`, `starts_too_soon`, `duration_out_of_range`, `product_unavailable`, `insufficient_stock`, `idempotency_key_required\|invalid\|reuse` |
| `GET /shops/:shopId/auctions?status&limit&cursor` | `ShopScoped('products.read')` | limit 1–100 (default 20), opaque cursor over `(startsAt DESC, id DESC)` | `200 auctionPageSchema {items, nextCursor}` | `400 validation_failed`, `400 invalid_cursor`, `401`, `404 shop_not_found` |
| `GET /shops/:shopId/auctions/:auctionId` | `ShopScoped('products.read')` | — | `200 auctionMemberSchema` | `404 auction_not_found` (body identical for foreign and unknown) |
| `POST /shops/:shopId/auctions/:auctionId/cancel` | `ShopScoped('products.write')` | — (no body) | `200 auctionMemberSchema` (repeat on `CANCELLED` is `200`, no change) | `404 auction_not_found`; `409 auction_has_bids`, `409 auction_not_cancellable` |

| `GET /auctions/:auctionId/my-bid` | `Firewall()` | — | `200 myBidSchema {maxAmountMinor \| null, isLeading, priceMinor}` | `401`, `404 auction_not_found` |

## Schemas (fields)

- `auctionMemberSchema`: `{id, shopId, productId, title, currency, startingPriceMinor, minIncrementMinor, reservePriceMinor | null, startsAt, endsAt, originalEndsAt, status, statusReason | null, priceMinor, bidCount, leaderAlias | null, reserveMet, winnerOrderId | null, finalPriceMinor | null, version, createdAt}`. No user ID, no maximum. Timestamps ISO-8601 UTC.
- `auctionPublicSchema`: `{auctionId, productId, shopId, title, currency, status, startsAt, endsAt, priceMinor, minimumNextMaxMinor, bidCount, hasReserve, reserveMet, leaderAlias | null, version, serverTime}`. Replaces the loose `auctionPublicSchema` in `bff/upstream.ts` under the same exported name (`auctionsResponseSchema` stays the array).
- `bidResultSchema`: `{outcome: 'leading'|'outbid'|'raised', priceMinor, youAreLeading, leaderAlias, endsAt, version, serverTime, minimumNextMaxMinor, reserveMet, hasReserve}`.
- `minimumNextMaxMinor`: for a bidder who is not the leader: `priceMinor + minIncrementMinor` once a leader exists, `startingPriceMinor` when there is none. (AS-10: price 1000, increment 500, `1500`.)
- Route policies: `auction.bid` (existing: 10 / 10 s per user, token bucket, fail closed) and `auctions.read.ip` (new: 600 / min per address, fail open) added to `auctionsRatePolicies`.
- Fail-closed mapping: a limiter store failure on the bid route is `503 bid_unavailable` + `Retry-After: 2` (the guard's closed mode is mapped by an exception filter for this route to the stable code), a tenancy lookup failure or timeout the same.
- Status mapping from the pure domain: `AuctionNotStartedError`, `AuctionClosedError`, `BidTooLowError`, `BidNotIncreasingError`, `ShillBidForbiddenError`, `BidUnavailableError`, `AuctionHasBidsError`, `AuctionNotCancellableError`, `AuctionExistsForProductError`, … each carries `code` and extension members; one `AuctionExceptionFilter` maps them to problem+json (no controller branching, II.1).
