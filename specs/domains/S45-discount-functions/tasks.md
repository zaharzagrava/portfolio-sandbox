## Implementation strategy

MVP = Phase 1 + Phase 2 + US1 (management API on real persistence). Then US2 (judge) and US3 (checkout and the orders cut-over), then US4 hardening. Each phase ends green on its narrow `test-spec.sh` run; the whole suite runs once in the last task. Runtime proofs (boots, fresh stack, benchmark, container probe) are deferred to the final checkpoint.
