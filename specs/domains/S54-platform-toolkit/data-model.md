# Data Model: S54 — Platform toolkit

One persistent table (`IdempotencyKey`, owner `infrastructure:idempotency`, IX.3 allowlist). Everything else is in-process state.

## Persistent: `IdempotencyKey`

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` PK (UUIDv7 generated by the app) | no FK anywhere (IX.4) |
| `scope` | `varchar(160)` NOT NULL | `principal:<id>` or `ip:<clientIp>`; never null |
| `key` | `varchar(128)` NOT NULL | validated 8–128 chars `[A-Za-z0-9_-]` |
| `fingerprint` | `char(64)` NOT NULL | hex SHA-256 (see research R-10) |
| `state` | `varchar(16)` NOT NULL | `in_flight` \| `completed` (CHECK) |
| `claim_token` | `uuid` NOT NULL | identifies the claiming attempt; used for conditional completion/release |
| `lock_expires_at` | `timestamptz` NOT NULL | claim time + lock (default 60 s) |
| `response_status` | `smallint` NULL | set on `completed` |
| `response_headers` | `jsonb` NULL | allowlisted headers only (`Content-Type`, `Location`, `ETag`) |
| `response_body` | `bytea` NULL | NULL when over 256 KiB (`replay_unavailable`) |
| `body_stored` | `boolean` NOT NULL DEFAULT true | false when the body was over the cap |
| `created_at` | `timestamptz` NOT NULL | |
| `expires_at` | `timestamptz` NOT NULL | created + TTL (24 h default, route override ≤ 7 d) |

Indexes / constraints: `UNIQUE (scope, key)` (the atomic claim, III.6); `INDEX (expires_at)` for the purge.

Migration `20261009120000-idempotency-key.js`: expand-only `CREATE TABLE`, `SET LOCAL lock_timeout = '3s'`, reversible `down`. Registry: `IdempotencyKey: 'infrastructure:idempotency'` in `db/ownership.ts` (same PR).

State transitions (all conditional updates asserting one affected row, III.7; the table is technical so no history row):

```
(absent) --claim INSERT--> in_flight --complete (token match)--> completed --purge--> (absent)
in_flight --release (non-final failure, token match)--> (absent)
in_flight --lock expired, takeover (conditional update, new token)--> in_flight
```

Validation rules: key format and single header (FR-063); body over 256 KiB → `body_stored=false`; facility's own `409/422` never stored (FR-065); only errors flagged `idempotencyFinal` are stored.

### Circuit breaker state machine

```
CLOSED --(calls ≥ minimumCalls AND failureRate ≥ threshold, slow calls count as failures)--> OPEN
OPEN   --(clock ≥ openedAt + openDurationMs)--> HALF_OPEN
HALF_OPEN --(all halfOpenCalls succeed)--> CLOSED
HALF_OPEN --(any failure)--> OPEN
```
`4xx` responses never count as failures. In OPEN, `execute` returns the fallback (flagged `degraded`) or rejects `circuit_open`.

### Shutdown sequence

```
running --signal--> notReady --drainDelay--> stopAccepting --in-flight done | requestDrainTimeout--> tasks(order asc) --> app.close --> exit(0|1)
   any state --hardTimeout--> exit(1) "forced shutdown"
```
