# Research: S33 — Search Autocomplete

- **R-1 S32 dependency state.** Read 2026-10-10: `ProductTitleSuggester` (S32 T102, open) and the `surface` column of `search_queries` do not exist yet (`clickhouse/030_search_queries.sql` has no `surface`; `search-queries.projector.ts` does not write it; only `ElasticsearchService.suggestTitles` exists). Decision: S33 defines a `CatalogTitleSource` port shaped like S32's (`suggestTitles`, `suggestTitlesFuzzy`, abort signal, typed timeout). The adapter wraps `ProductTitleSuggester` once S32 exports it; until then it sits over the in-domain `ProductIndexPort` with the visibility filter, and the fuzzy method is the S32 follow-up in gaps.md. Alternative rejected: keep `ElasticsearchService` (breaks D-16, ignores visibility). The log reader treats a missing `surface` column as `'http'`; S33 does not alter the table.
- **R-2 Query reducer.** S32 ships `domain/query-text.ts` (`normaliseQuery`, `logForm`, `redactQuery`, `MAX_QUERY_LENGTH`). Reuse it, then lower-case; delete the local `normalizeQuery`.
- **R-3 Rate limiting.** `rate-limit-policies.ts` already owns `discovery.*` policies; add `discovery.suggest` (sliding window, 600/min, key `ip`, `failMode: 'open'`) and use `@RateLimit('discovery.suggest')` instead of `skipThrottle`.
- **R-4 Validation and errors.** Follow `api/search.controller.ts`: take `@Query() Record<string, unknown>`, parse with a `.strict()` Zod schema, map failures to `validation_failed` problem+json.
- **R-5 Job options.** `handler-options.ts`: `maxRuntimeMs` must be ≥ `leaseMs`, default 15 min. Lease stays 600 000 ms (FR-030); set `maxRuntimeMs: 600_000` explicitly. The log query gets its own timeout below that.
- **R-6 Pointer compare-and-set.** Redis Lua script comparing sortable UTC-timestamp versions; a separate explicit path sets the pointer backwards for operators (AS-47).
- **R-7 Deterministic build.** Version from the injected `Clock`; query orders by `searchers DESC, query ASC`; `uniqExact(user_hash)` replaces `uniqCombined`; `FINAL` plus distinct `event_id`; eligibility re-applied in `domain/query-eligibility.ts`.
- **R-8 Breaker and cache.** Pure `catalog-circuit` state machine with injected clock; bounded in-process prefix cache, 60 s TTL, failures never stored.
- **R-9 Transactions.** The five autocomplete files hold no `sequelize.transaction` and no `// S54 T037 audit` comment (read 2026-10-10); nothing to migrate or add.
- **R-10 Sibling files.** Web (`catalog.ts`, `search/page.tsx`) is W02's; the policy registry is S50's; the port methods are S32's. All recorded under "Sibling-spec follow-ups" in gaps.md.
