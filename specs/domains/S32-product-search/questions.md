- [BREAKING] `POST /admin/search/reindex` enqueues a job with an hourly idempotency key and answers `202 {jobId}` (`search-admin.controller.ts:69`; a second call in the same hour is silently deduplicated even if the first finished) → a run resource `{runId, kind, status}`, one active run (`409 reindex_in_progress`), `GET` status and list, `POST …/cancel`, `POST /admin/search/rollback`, a state machine with history → III.7 (conditional transitions), operability of a long job.
