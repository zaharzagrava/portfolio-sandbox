# Tasks: S39 — Analytics ingestion and A/B testing

**Input**: `plan.md`, `spec.md`, `test-plan.md`, `gaps.md`, `questions.md` (defaults accepted), `research.md`, `data-model.md`, `contracts/ingest-api.md`, `contracts/experiments-api.md`, `quickstart.md`.
**Tests**: required (constitution VII, `test-plan.md`). For every `test-plan.md` row the failing-test task comes before the code task. A scenario id (`AS-nn`) stays in the `it` title when a file is split or renamed (L-017).

## Conventions

- `BE` = `packages/backend`; `DOM` = `packages/backend/libs/domains/experimentation`; `CON` = `packages/contracts/src`; `EDGE` = `packages/edge-be`. Run backend commands from `packages/backend`.
- E2E: `/opt/sdd/repo/scripts/sdd/test-spec.sh <file>`, one file per process (L-008). Every e2e creates its own experiments and events with fresh ids and truncates Postgres/ClickHouse in `beforeEach` (L-005, L-006); a test that breaks Kafka, Redis, the cache or ClickHouse restores it in `afterEach` (L-013). No "A or B" assertions; an environment limit is recorded `blocked`, never as a pass (L-003). Frozen clock, no real sleeps except a polling helper with a deadline (L-007).
- Never use git checkout/restore/reset/stash/clean; undo by hand. Never create or edit `*.reviewed.json`. No new `sequelize.transaction`; use `TransactionRunner.run` (rule 4).
- Story labels: US1 ingest (AS-01–11), US2 store and dedupe (AS-12–16), US3 assignment (AS-17–24), US4 exposure (AS-25–29), US5 admin lifecycle (AS-30–41), US6 results (AS-42–53), US7 operations (AS-54–57).
