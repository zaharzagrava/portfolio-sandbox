# W07 — Test plan

One row per acceptance scenario of [`spec.md`](spec.md). Each edge case is proven once, at the lowest layer that can prove it (constitution VII.7, VII.8). The Playwright journeys are happy paths only; header checks are plain HTTP assertions made with Playwright's `request` fixture in the same suite. Visual rows are Playwright screenshots (`toHaveScreenshot`) taken at mobile 390 × 844 and desktop 1280 × 800, in light and dark where stated. "—" means the layer does not apply. Visual file for all rows: `packages/web/tests/app-shell.visual.spec.ts` (top-level `describe('W07 app shell layout')`).

Suite names (top-level `describe`): `W07 app shell` (`tests/app-shell.spec.ts`), `W07 security headers` (`tests/security-headers.spec.ts`), `W07 developer docs` (`tests/developer-docs.spec.ts`), `W07 widget checkout application` (`tests/widget-embed.spec.ts`).

## Edge-case index (each appears once)

| Edge case | Row |
|---|---|
| hostile or very long path never echoed | AS-09 |
| error message / stack leaking into the UI | AS-10 |
| slot throws or is slow | AS-04 |
| status × `Retry-After` wait text boundaries | AS-13 |
| nonce reused between responses | AS-16 |
| payment hosts on other pages | AS-18 |
| Back after sign-out | AS-20 |
| unlisted image host | AS-22 |
| cookie list drift | AS-23 |
| wide code or tables at 320 px | AS-30, AS-31 |
| `page` name containing token or query | AS-35 |
| identity message from wrong window or origin | AS-40 |
| configuration invalid at start-up (wildcard host, missing `SITE_URL`) | AS-18, AS-34 |
