# W07 — Research and decisions

No `NEEDS CLARIFICATION` remains. Each item: Decision / Rationale / Alternatives.

- **R-01 Nonce CSP.** Decision: `packages/web/proxy.ts` (Next 16's name for middleware) generates a random nonce (≥ 16 bytes, base64), sets `Content-Security-Policy` on the request (so the framework applies the nonce) and on the response, and `x-nonce` on the request. Matcher excludes `_next/static`, `_next/image`, `favicon.ico`, `health`, `widget`, `api` and prefetch requests. All policy text comes from the pure `buildCsp`. Rationale: Next guide *Content Security Policy*. Alternative: hash/SRI policy (experimental; rejected, Q1).
- **R-02 Dynamic rendering.** Decision: documents render per request; `cacheComponents` stays for `"use cache"` data (docs description, ≤ 5 min). Where a page fails the build with uncached data outside `Suspense`, wrap the dynamic part in `Suspense`; do not weaken the policy. Alternative: static shell (incompatible with nonce).
- **R-03 Static headers.** Decision: one module `lib/security/headers.ts` (`staticSecurityHeaders`, `noReferrerPaths`, `noStorePaths`) used by `next.config.ts` `headers()` and tests. The general `Referrer-Policy` rule excludes `noReferrerPaths` by its `source` pattern, so one effective value results. `noStorePaths` also feeds `robots.ts`. HSTS in production only; `poweredByHeader: false`.
- **R-04 Configuration.** Decision: pure parser `lib/config-parse.ts` (zod; usable from `next.config.ts`) and `lib/config.ts` (`import 'server-only'`, parses once, fails fast naming the variable). Hosts must be exact `https://host[:port]` (`http:` only in development); wildcards rejected; `SITE_URL` required and `https:` in production. Image `remotePatterns` and `img-src` come from the same parsed list; the local MinIO host is allowed only in development.
- **R-05 Theme and nonce.** Decision: keep `next-themes`; pass `nonce` read from the `x-nonce` request header in a dynamic leaf of the root layout; Light/Dark/System dropdown; reduced motion handled in CSS.
- **R-06 Docs viewer.** Decision: replace `swagger-ui-react` with a small read-only client renderer over the validated OpenAPI JSON, dynamic-imported on `/developers/docs` only, descriptions rendered with `react-markdown` without raw HTML, links validated to `http:`/`https:`; remove the dependency. Rationale: AS-29 forbids request sending; Swagger UI ships try-it-out, is heavy and CSP-hostile. Alternative: Swagger UI with submit disabled (still heavy, CSP risk).
- **R-07 Docs data route.** Decision: web rewrite `/api/developers/openapi.json` → `${PUBLIC_API_URL}/docs-json` placed before the generic `/api/:path*` rule (`PUBLIC_API_URL` defaults to `API_URL`). Finding: today `apps/public-api` serves `docs-json`, while the dev monolith at :8000 answers `404` for `/api/developers/openapi.json`, so P9 also adds a core route returning the same description so the page works in the local stack. Playwright falls back to a `page.route` fixture only for the unavailable-state tests.
- **R-08 Sibling slots absent.** Finding: `AccountSlot`, `SearchBox`, `CartBadge`, `AssistantLauncher`, `ChatNavBadge`, `isAdmin`, `problemFromError` and `track` do not exist in `packages/web` yet. Decision: W07 creates each at its contract path with a minimal body (account slot wraps today's `useAuth` UI; cart badge reads the existing cart count; assistant launcher wraps the existing assistant sheet trigger; `track` posts `page_view` to `/api/events`), headed `// Stand-in for the W0x contract: the owner replaces the body, never the name or props`. The `toggle-assistant` event and the layout-level `AssistantSheet` mount are removed. Each is a sibling follow-up. Alternative: block on the siblings (impossible in this run).
- **R-09 Absolute API origin and token in `lib/api/client.ts`.** Decision: W07 does not redesign it (W01). Under `connect-src 'self'` an absolute origin breaks in production, so P1 first checks that calls are relative via the rewrites; if the code still falls back to an absolute address, W07 changes only that fallback to same-origin and records it as a W01 follow-up.
- **R-10 Error reference.** Decision: `error.tsx` shows `error.digest`; `ErrorState` shows `Problem.requestId`; nothing else. `401` renders nothing.
- **R-11 Page names.** Decision: `pageNameFor(pathname)` matches a static template list in `lib/routes/page-name.ts`; a test globs `app/**/page.tsx` and fails when a page has no template; unmatched → `/not-found`; query and fragment dropped.
- **R-12 Toasts.** Decision: `sonner`, one `<Toaster />` in the providers, `visibleToasts` 3, 5 s duration for success/info, persistent errors and action toasts, `closeButton`, text only.
- **R-13 Widget bundle.** Decision: route handler `app/widget/v1/app.js/route.ts` serving a script built from `lib/widget/messages.ts` by an esbuild script (`build:widget`); headers `Content-Type: application/javascript`, `Cross-Origin-Resource-Policy: cross-origin`, `nosniff`, `Cache-Control: public, max-age=31536000, immutable`; excluded from the proxy matcher. URL configurable by `WIDGET_APP_BUNDLE_URL`.
- **R-14 `POST /api/csp-reports`.** Decision: controller in the platform-toolkit area, anonymous, accepts `application/csp-report`, `application/reports+json` and `application/json`, parses leniently, logs the violated directive and the blocked host (scheme and host only), always `204`, rate limited by the S54 throttle. No DB access.
- **R-15 Criteria no automated test proves.** SC-004 (CLS), SC-005 (two taps), SC-006 (1 s message and support lookup) go to `quickstart.md` Ops artifacts and `specs/UNVERIFIED.md`, status "not run".
- **R-16 Package manager.** Decision: pnpm (workspace); the stray `packages/web/package-lock.json` is left alone (not mine to delete) and noted.
