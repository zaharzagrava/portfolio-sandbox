## LOCAL

- [LOCAL] Times are UTC only ("YYYY-MM-DD HH:mm UTC" in `<time>`) → audit and expiry are compared across admins and services; also no server/client hydration difference.
- [LOCAL] No polling of the editor → a second admin's change is caught by `expectedVersion`, refocus refetch and tab change; live collaboration is not a goal.
- [LOCAL] Conflict UI offers **Load latest** and **Keep editing** only (no merge or diff) → merging definitions is not needed for a platform-admin audience of a few people.
- [LOCAL] Forbidden is a page-level panel, not Next's experimental `forbidden()` / `forbidden.tsx` (needs `authInterrupts`) → avoid an experimental API; the data is never requested for a non-admin either way.
- [LOCAL] `/admin` keeps its temporary redirect in `next.config.ts` → leaves `/admin` free for a future overview.
- [LOCAL] Weight inputs are percent with two decimals, sent as basis points → S38's unit is basis points; admins think in percent.
- [LOCAL] Starter definition is one "On/off flag" constant; no templates or JSON import → smallest useful default.
- [LOCAL] Unknown operator or attribute returned by the API renders the rule as read-only JSON → forward compatibility without breaking the page.
- [LOCAL] No search box on the list → S38's list has no search parameter; at most 500 flags; a `q` prefix parameter is a gap, not a client-side filter.
- [LOCAL] Unsaved-changes protection by `beforeunload` plus a discard dialog for in-app links → mechanism left to the implementation, outcome fixed (AS-25).
- [LOCAL] Offline banner copy reused from W04; no code shared until one is published.
- [LOCAL] Draft never persisted (no storage) → flag values of client-side flags are visible to the public but others may not be; VI.2 forbids tokens, and the draft is simply kept in memory.
- [LOCAL] After a session ends mid-edit the draft is lost (toast says so only when dirty) → no safe place to keep it across a sign-in without storage.
