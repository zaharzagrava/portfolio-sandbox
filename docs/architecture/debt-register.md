# Architecture Debt Register

Every known violation of constitution v3.1.0 left by the refactor, with who pays it. This is the one
place spec writing reads debt from: `scripts/sdd/spec-prompt.md` copies each domain's open rows into
that capability's `gaps.md`, and the implementation loop pays them under test.

- **Resolved by** is either a Phase 3 step ([`sdd-runbook.md`](sdd-runbook.md) §1c) or capability IDs
  from [`scripts/sdd/capabilities.tsv`](../../scripts/sdd/capabilities.tsv).
- **Origin** is the plan that found the item (`specs/00N-*/plan.md`).
- Close a row by setting **Status** to `resolved (<where>)`. Don't delete it.

## Commands

```bash
cd packages/backend
pnpm check:boundaries                 # dependency-cruiser, constitution X.4/X.5/X.8 (errors fail; cycles warn: D-11/D-12/D-15/D-17)
pnpm check:table-ownership            # D-7 + D-12 report, per domain (exits 0)
pnpm check:table-ownership --strict   # exits 1 on any finding: make it a CI gate once D-7/D-12 are paid
pnpm check:module-graph               # runtime barrel cycles, one process per app (must stay 9/9 ✓)
pnpm check:model-registry             # every app's Sequelize model set wires its associations, offline (10/10 ✓)
```
