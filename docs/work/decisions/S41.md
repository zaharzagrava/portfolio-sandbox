- **S41.D-02** When a competitor's robots.txt cannot be read, should we skip the page or crawl it anyway?

- **S41.D-03** Who receives a price-drop alert, and when does a seller get one?
  - default: every owner of the shop gets one alert when the competitor is below your price in the same currency and lower than the watch's previous evaluated price; it is also checked at registration, so a new watch on an already-seen URL can alert at once; different currencies give no alert
  - alternatives: alert only the shop's main owner; or alert only on drops after registration, never at registration
  - if wrong: alert spam to every owner, or missed alerts that sellers rely on to reprice; today a second shop on the same URL never gets an alert
  - source: "Alert rule: per-watch evaluated price, evaluated on every" ([BREAKING])
  - status: open

- **S41.D-04** What should the API do with a price it cannot read with certainty (missing currency, ambiguous format)?

  - alternatives: assume the shop's own currency when the page gives none; or accept ambiguous formats using a per-country guess
  - if wrong: too strict means some competitors never show a price; too lenient means false alerts and wrong charts that sellers act on
  - source: "Price parsing: exact decimal, currency exponent per ISO 4217" ([BREAKING])
  - status: open

- **S41.D-05** Which competitor pages may we follow and fetch?

  - source: "Redirects: same host only, `https` only, at most 3 hops" ([BREAKING])
