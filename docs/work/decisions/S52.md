- **S52.D-05** What happens to counter increments if the flusher crashes, and which limits apply to counters?

- **S52.D-06** Which cache entries are too big to cache, and is a cache-key rename acceptable for existing callers?
  - default: Entries over 256 KiB (max 1 MiB) are returned but not cached. Keys must be namespaced with `:`, at most 512 bytes, with no whitespace. Any key found without a namespace is renamed on its owner's next version bump, which means a one-time cold cache for that key.

  - if wrong: Large responses (big lists or catalogs) are never cached and hit the database every time, which means slower pages and higher cost. A forced rename causes a cold cache and a brief load spike.
