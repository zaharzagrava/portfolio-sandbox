# Architecture Debt Register

place spec writing reads debt from: `scripts/sdd/spec-prompt.md` copies each domain's open rows into
that capability's `gaps.md`, and the implementation loop pays them under test.

- **Resolved by** is either a Phase 3 step ([`sdd-runbook.md`](sdd-runbook.md) §1c) or capability IDs
  from [`scripts/sdd/capabilities.tsv`](../../../scripts/sdd/capabilities.tsv).
- **Origin** is the plan that found the item (`specs/00N-*/plan.md`).
- Close a row by setting **Status** to `resolved (<where>)`. Don't delete it.

## Paid per domain

The rows above name many domains; a row closes when the last one is paid. What each capability has paid, with the check that proves it:

- **S16 (`statements`), implemented 2026-10-15** - the commit that carries `specs/domains/S16-seller-statements/tasks.md` fully ticked.
  - **D-12**: statements read no order, catalog, tenancy or ledger table; sale, payout and ledger facts arrive as `order.paid`, `payout.paid` and `ledger.journal_posted` v2 events into statements-owned tables, shops through `ShopQueryService` (`pnpm check:table-ownership --strict` lists no `statements` row; `domain/boundaries.spec.ts` pins it).
  - **D-6/D-7**: layers `api/ application/ domain/ infra/`, SQL only in `infra/`, no foreign model. `.tx.baseline` of the domain reads 0 (both audited `sequelize.transaction` sites use `TransactionRunner`).

- **S17 (`billing`, subscriptions half), implemented 2026-10-15** - the commit that carries `specs/domains/S17-subscriptions/tasks.md` ticked.
  - **D-6**: `api/` and `application/` import no `infra/` path (ports and tokens in `domain/ports.ts`, SQL only in `infra/*.repository.ts`, the provider behind `BILLING_GATEWAY`); `BillingJobs` is a thin shell over `RenewalService`, `ChargeService` and `AttemptResolutionService`. S18's `EntitlementsService`/`UsageService` keep their direct SQL until S18 moves them. `pnpm check:boundaries` is clean.
  - **D-7**: the barrel exports no model; `check:table-ownership --strict` lists no `billing` row (the sandbox flag comes from `ShopQueryService`, shop lifecycle from events).
  - **D-8**: the barrel exports `BillingModule`, `BillingWorkerModule`, `BillingConsumerModule`, the policies, the events and `SubscriptionBasisService`; apps import only those. `UsageProjector` stays exported until S18 (the projector app wires it).
  - `.tx.baseline` of the domain reads 0 (`TransactionRunner.run` only; the migrations use their own short transactions).
- **S47 (`assistant`, knowledge half), implemented 2026-10-13/14** - the commit that carries `specs/domains/S47-rag-help-center/tasks.md` fully ticked.
  - **D-6**: the knowledge files in `api/` and `application/` import no `infra/` path and no connection; ports and tokens in `domain/ports.ts`, SQL only in `infra/pg-*.repository.ts` (`pnpm check:boundaries` clean).

  - **D-8**: the barrel exports the three knowledge modules, `KnowledgeSearchModule`, the search service with its error and scope types and the evaluation maths; the S46 symbols it still exports are listed in its header.
  - **D-14, partially paid**: the knowledge half uses no `LlmMeter` and no `UsageService` and publishes `llm.call_completed` through `CallRecorder`; `./infra/llm/*` is imported only by the three interim adapters (`answer-model`, `call-recorder`, `moderator`). The row stays open until S46 moves the provider to `libs/infrastructure/llm`.
  - `.tx.baseline` of the domain reads 0 (the three audited `sequelize.transaction` sites use `TransactionRunner`).
- **S46 (`assistant`, shopping half), implemented 2026-10-15** - the commit that carries `specs/domains/S46-shopping-assistant/tasks.md` ticked.
  - **D-6**: `api/` and `application/` of the shopping half import no `infra/` path; ports and tokens in `domain/assistant-ports.ts`, adapters in `infra/redis-*.ts`, `infra/scylla-conversation.repository.ts`, `infra/moderation.adapter.ts` (proved by AS-76 in `assistant-platform.e2e-spec.ts`; `pnpm check:boundaries` clean).

pnpm check:module-graph               # runtime barrel cycles, one process per app (must stay 9/9 ✓)
pnpm check:model-registry             # every app's Sequelize model set wires its associations, offline (10/10 ✓)
