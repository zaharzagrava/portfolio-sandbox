# Interview Prep: Senior Node.js / Full-Stack Engineer

In-depth prep docs for senior Node.js / full-stack interviews: Nest, Next, PostgreSQL, Redis, AWS, Kubernetes, distributed and financial systems, plus system design and coding patterns.

Every doc ends with an **Interview Q&A** section of concise model answers. Use those for the last review before an interview.

Many sections also carry an **In this codebase** block that links the idea to the code in this repository that implements it (generated by `pnpm docs:theory`, see the root README). Own exercises go in `my-practice/`, which is gitignored.

## 3-week study plan

| Week | Days 1–2 | Days 3–4 | Day 5 | Daily |
|---|---|---|---|---|
| 1 | State, APIs, deprecation: 09/01, 04/01, 04/02 | SLOs, web security, probes: 07/01, 05/01, 08/01 | Prepare your own behavioral stories | 2 LeetCode (11/03 patterns) |
| 2 | Node (02/*) + JS/TS (01/*) | Databases (03/*) | Distributed (06/*) | 2 LeetCode (DP-heavy) |
| 3 | System design (10/*): practice 2 designs out loud | Frontend (09/02–03), DevOps (08/02–04) | Behavioral stories + mock interview | 1 timed problem + review Q&A sections |

**Practice method**: for each doc, close it and explain the Q&A answers **out loud** (record yourself). If you can't explain something in two minutes without notes, reread that section.

## Notes on using these docs

- **Version-specific details** (Next.js 15/16, React 19, Node 24) are flagged in the docs as fast-moving. Check them against the version you actually use.
- **Algorithm code is tested.** Every algorithm snippet was run on Node 24, and the DP solutions were checked against brute force on random inputs. Node's built-in TypeScript support rejects TS constructor shortcuts like `constructor(private x)`, so the templates avoid them, which helps if you run `practice.ts` with plain `node`.
